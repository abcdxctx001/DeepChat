# 🃏 改版争上游（2人版）

一个"手牌上限5张"的改版争上游，1人 vs 随机 AI。包含**浏览器版**（HTML）与**命令行版**（Python）两种玩法，以及完整的核心逻辑测试。

## 游戏规则

1. **牌具**：1副54张扑克（含大小王）。**先手随机**，每人开局抽5张。
2. **手牌上限5张**：每轮结束（有人出牌后对方不要）时，从**第一个不要的人**开始，依次补牌到5张；牌堆无牌则停止补牌。
3. **牌型**（与普通争上游一致，但顺子由5张起步改为2张起步）：
   - 单张、对子、三张、三带一、三带二
   - 顺子：**2~5张**连续（3~A，不含2与王）
   - 炸弹（四张相同）、王炸（大小王）
4. **压牌**：同牌型比大小（顺子需**等长**、比最大牌）；炸弹可压任意非炸弹牌型；王炸最大。
5. **胜负**：**手牌率先出完者胜**，无论牌堆是否还有剩余牌。
6. **点数**：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。

> 补充：三带一/三带二比较的是三张部分的点数；补牌顺序遵循"第一个不要的人先补"；赢下出牌权的人（最后出牌者）下一轮先出。

## 运行方式

### 浏览器版（推荐）
直接双击打开 `zhengshangyou.html`，或命令行执行：
```
start zhengshangyou.html
```
- 点击手牌选中/取消，按 **出牌** 打出
- 压牌时可选择 **不要**
- **💡提示** 可帮你找出一个合法出法
- 右侧为完整对局记录，底部可展开规则说明

### 命令行版
```
python play_cli.py
```
输入手牌编号（如 `0,1`，逗号分隔）出牌；压牌轮输入 `p` 表示不要；`q` 退出。

### 自动对局演示
```
python play_cli.py --auto
```

### 回合制对局会话（亲自决策）
适合一步步深思熟虑地对弈，AI 回合自动执行，状态保存在 `session_state.pkl`：
```
python play_session.py new             # 新开一局
python play_session.py view            # 查看当前局面
python play_session.py play "0,2,4"    # 出牌（手牌编号，逗号分隔）
python play_session.py pass            # 我不要
python play_session.py hint            # 列出当前所有可出的合法牌型
```

## AI 策略

AI 严格按照需求实现为**纯随机**：每次从所有合法牌型中**等概率随机**选择一种；压牌时从所有能压住的牌型中随机选一个，若压不住则"不要"。无任何贪心/搜索策略，因此实力相当"随缘"，胜率对真人玩家而言取决于牌运与个人打法。

## 测试结果（已通过）

- **Python 核心**：牌型分析、压牌比较、牌型枚举（2000手牌交叉验证）、补牌顺序与牌堆耗尽场景、出完即胜场景；
  600局流程不变量（牌数守恒/手牌≤5/胜负判定）+ 3000局统计：玩家/AI 胜率各50%，平均63步/局，最长81步。
- **Node 核心**：33项断言全部通过；3000局模拟无异常。
- **浏览器版**：headless Chrome 自动化驱动完整对局（多局），无 JS 错误，结束弹窗正常。
- **命令行版**：20局 `--auto` 自动对局 + 交互冒烟测试全部通过。

## 设计细节

- 牌型按 `(类型, 主点数, 张数)` 去重，三带一/三带二带不同牌视为同一牌型（比较只看三张部分）。
- 炸弹无"同点"冲突（一副牌同一花色点数唯一），王炸/对王炸在真实牌局中不可能互压。
- 浏览器版使用 `token` 机制防止"重新开始"后残留的 AI 定时器干扰新对局。
