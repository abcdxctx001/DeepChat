📜 规则说明（点击展开/收起）
基本玩法：2人对战，1副54张扑克。每人手牌上限 5张，开局各抽5张； 先手随机。依次出牌，若对方不要，则从第一个不要的人开始依次补牌到5张 （牌堆无牌则停止）。手牌率先出完者胜。
合法牌型：单张、对子、三张、三带一、三带二、顺子 （2~5张连续，3~A，不含2和王）、炸弹（四张）、王炸（大小王）。
压牌规则：同牌型比大小（顺子需等长比最大牌）；炸弹可压任意非炸弹牌型； 王炸最大，压一切。
点数大小：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。
操作：点击手牌选中/取消，按“出牌”打出；压牌时可选“不要”；“💡提示”帮你找一个合法出法。
