给自己取个昵称

无需注册，昵称只用来标记你的消息。

昵称不做密码校验；被锁定的昵称只能由它绑定的 IP 使用。

Headless API

网页与 headless 客户端读写同一条消息流，所有接口都是普通 HTTP + JSON。

Base URL /
常用请求
  • 昵称通过 ?nickname=、JSON nickname 或 X-Nickname 请求头传入。
  • 读取：GET /api/messages；发送：POST /api/messages；上传：POST /api/upload。
  • 长轮询：?after_id=&since_rev=&wait=25，有新消息或撤回 / 权限变更立即返回。
  • 撤回：POST /api/messages/{id}/recall；撤销：/unrecall（本人或管理员）。
  • 权限：GET /api/admin/identities、POST /api/admin/identities/{nickname}，带 X-Chat-Client: api 时不受昵称锁限制。

权限管理

昵称就是身份。可以任命管理员、禁言（定时 / 永久）、锁定昵称。

没有匹配的昵称

锁定只对网页前端生效：被锁定的昵称只有它绑定过的 IP 能登录，该 IP 也不能再换别的昵称； API 调用带 X-Chat-Client: api 时不受锁定限制。
