# 🎮 虚拟炒股模拟器（零风险练手版 · Tick级行情版）

为**不敢投入真金白银**的投资新手设计的模拟炒股游戏。用 20 万元虚拟资金，
在完全模拟 A 股规则的环境里练习选股、买卖、仓位管理，亏光了也不心疼！

> ✨ **本版本核心升级：行情粒度从「天」细化到「tick」（秒级/毫秒级）**，
> 支持盘中任意时刻买卖、可调节时间流速，并新增当日分时图。

## 快速开始

- **Windows**：双击 `start_game.bat`
- 或者命令行执行：`python stock_sim.py`

> 需要 Python 3.8+（自带 tkinter 即可，无需安装任何第三方库）

## 操作说明

1. 左侧行情表点击股票 → 查看 K 线与均线（或点击右上角 **⏱ 切换分时图** 看当日逐 tick 走势）
2. **K线交互**：鼠标滚轮缩放（10~500根）、按住左键拖动平移看历史、双击复位
3. 右侧输入数量（100 的整数倍）→ 点【买入】或【卖出】，**盘中随时成交（按最新 tick 价）**
4. 支持"最多可买"、1/4仓 / 1/2仓 / 全仓快捷按钮、一键清仓
5. 底部日内控制条：
   - 【⏱ 下一Tick】：单步推进一个 tick（秒级/毫秒级节奏）
   - 【▶ 自动交易】：按设定流速连续运行，随时可暂停
   - 【流速】滑块 + 档位按钮：1~10000 tick/秒
   - 【粒度】：秒级(1s) / 100ms / 10ms / 毫秒级(1ms)，**切换即时生效，不重置进度**
   - 右侧实时显示当日 tick 进度（如 `tick 3000/14400`）
6. 【⏭ 下一交易日】快进到次日开盘；【🤖 量化实验室】让程序自动炒股
7. 【帮助】按钮内有完整规则与新手小贴士

## 量化策略说明

| 策略 | 思路 |
|------|------|
| 双均线趋势 | MA5>MA20 买入、MA5<MA20 卖出，经典趋势跟踪 |
| RSI超卖反转 | RSI14<30 超卖买入、>70 超买卖出，均值回归 |
| 动量轮动 | 每20个交易日重仓近20日涨幅前2的股票 |
| 智能定投 | 每5个交易日拿出现金30%等权买入全部股票 |

> 每个策略使用独立的 200,000 元虚拟账户，与你互不干扰，可公平对比"人 vs 程序"。
> 策略在每个交易日**收盘时**按收盘价运行一次（自动交易跨日 / 点【下一交易日】时触发）。

## 行情模型说明

游戏支持两种行情模式（标题栏右侧显示当前模式，底部按钮可切换）：

**📊 真实行情模式（默认）**
- 自动加载你下载的真实 A 股行情 CSV（`a股大盘股行情/` 目录，8 只股票近 100 个交易日 OHLCV）
- 开局直接使用真实 K 线，当前价 = 真实最新收盘价
- 真实数据用完后，用**从真实数据统计校准**的单因子模型续接：
  个股 beta、波动率、市场波动水平全部从这 100 天真实行情估计
- 所以：行情从"真实世界"出发，未来充满不确定性

**🎲 纯模拟行情模式（备选）**
- 程序生成全部行情，融合 **A 股五大特征**（基于市场研究总结）：
  1. **Student-t（df=3~4）厚尾噪声** —— 尖峰厚尾，比正态多出数倍极端值（突发跳水/直线拉升）
  2. **EWMA 波动率聚集** —— σ²ₜ = 0.94·σ²ₜ₋₁ + 0.06·r²ₜ₋₁，恐慌期巨震 / 平静期缩量
  3. **复合泊松跳跃** —— 每月 1~2 次，跳幅 N(±2.5%, 1.2%)，形成跳空缺口
  4. **涨跌停截断** —— 主板 ±10%，极端日封板（一字板开=收）
  5. **两状态马尔可夫链** —— 牛市漂移 +0.06%/天，熊市 -0.06%/天（波动×1.2），每 20~60 天切换
- 个股层：β×市场收益 + 个股 t(4) 噪声 + 个股 EWMA 波动 + 涨跌停截断

**⏱ 日内 Tick 行情（本版新增）**
- 每个交易日生成日K后，日内价格沿「开盘 → 收盘」**随机桥路径**逐 tick 演化：
  每步 = 向收盘价的线性漂移 + 按 √(1/n) 拆分的 t 分布噪声，最后一步精确收在收盘价
- 惰性生成：**不预存整条路径**，无论粒度细到秒还是毫秒，内存恒定（每只股票只存当前价 + 分时采样点）
- 一字板（涨/跌停封板）日全天价格不动，与真实盘口一致
- 粒度切换即时生效：重新标定 tick 序号，保持当前模拟时刻不变

> 两模式都支持 tick 级买卖、分时图、K线、量化策略、存读档。行情仅供学习参考，不构成投资建议。
